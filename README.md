# UIU Health Care

A full-stack student healthcare support web application designed for United International University students.

## Overview

UIU Health Care provides students with quick access to emergency assistance, first-aid guidance, mental health resources, health awareness information, and nearby hospitals.

The platform includes separate Student and Admin dashboards with role-based access control.

## Core Features

- Emergency SOS system
- Real-time SOS notifications for administrators
- SOS status tracking
- First Aid Guidelines
- Mental Health Support
- Health Awareness
- Nearby Hospital Finder
- Student Dashboard
- Admin Dashboard
- Role-based authentication
- Emergency history and activity tracking
- Google Maps integration
